The lineup

Every system is built on one correlation, not a blend of everything

Instead of one strategy trading every pair, Quantistry runs a separate system per thesis — a shared currency, a shared risk-on/risk-off behavior, a shared region. Each one is backtested, scored, and can be allocated independently.

Deployment

One system, tuned for the account it runs on

A system's thesis doesn't change from broker to broker — but its risk sizing and order handling do. Every system in the lineup ships in four calibrations.

FIFO

Regulated brokers

Order sequencing and exits are reordered to satisfy first-in-first-out rules, with no hedged positions on the same pair, and no change to the underlying signal.

10X

10x accounts

Position sizing is recalculated against the higher leverage cap, so risk-per-trade stays the same fraction of equity regardless of account leverage.

STANDARD

Regular accounts

The default calibration. Full position sizing, no leverage or FIFO constraints, and the widest range of order types available.

PROP

Prop firms

Daily and maximum drawdown limits are enforced pre-trade, so a system stops itself before it can breach an evaluation or funded-account rule.
